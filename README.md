# ANONYMOUS1270 Studios

**Gaming. Tech. Beyond.**

The official website platform for ANONYMOUS1270 Studios — gaming, technology, reviews, news, videos, livestreams, events, tournaments, and creator/business media.

## Stack

- Next.js + React + TypeScript
- Tailwind CSS
- Supabase / PostgreSQL
- Vercel
- GitHub

## Project structure

The application is being built as a modular, production-ready platform with a public editorial site, tournament registration, CMS/admin foundation, SEO, analytics, and scalable content models.

## Development

1. Install Node.js LTS.
2. Install dependencies with `npm install`.
3. Copy `.env.example` to `.env.local` and fill in the required values.
4. Run `npm run dev`.
